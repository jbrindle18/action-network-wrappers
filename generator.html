What is this?

This tool themes an Action Network page wrapper - the frame (colours, fonts, logo, layout, footer and thank-you daisy chain) that wraps around your AN action.

How to use it

  1. Set your colours, fonts, logo and layout in the sections on the left, and build what people see after they take action in Daisy chain.
  2. Click Copy header and paste it into the Header box of your AN page wrapper. Then click Copy footer and paste it into the Footer box. (In AN: Details → Page Wrappers → Add New Wrapper.)
  3. Save the wrapper in AN, check it in AN's Preview, and set your action to use it.
  4. Save wrapper keeps a file of your settings. Next time, Import saved wrapper picks up where you left off - updated to the latest version of the template.
