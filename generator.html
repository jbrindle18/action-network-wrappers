What is this?
Beta - this tool is still being tested and refined. It works, but you may hit rough edges. Always check your wrapper in Action Network's own Preview before going live, and keep a saved copy of anything important. Any problems? Email hello@solidaritystudio.uk.

This tool themes an Action Network page wrapper - the frame (colours, fonts, logo, layout, footer and share buttons) that wraps around your AN action.

How to use it

  1. Set your colours, fonts, logo, layout and share options in the sections on the left.
  2. Click Copy header and paste it into the Header box of your AN page wrapper. Then click Copy footer and paste it into the Footer box. (In AN: Start Organizing → your group → Page wrappers → new/edit wrapper.)
  3. Save the wrapper in AN, and set your action to use it.

What each button does

  • Copy header / Copy footer - paste into AN's matching Header and Footer fields.
  • Save wrapper - saves your themed wrapper as a file you can reopen later.
  • Import saved wrapper… - applies a saved file's settings onto the latest template here.
